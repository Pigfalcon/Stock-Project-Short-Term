# Stock-Project-Short-Term
This project is based on my desire to learn more about Python, pandas, and statistical modeling in Python. My goal was primarily to learn, and a secondary goal was just curiosity about how much EPS reports affect short-term stock gains. I limited the data to just after COVID to try to limit some of the variance. Additionally, I wanted to see if there was a difference between small-cap and large-cap stocks. In the end, I found that both had statistically significant models, but their predictive power was irrelevant. Overall, there is a lot of info that affects the market that is not seen in the data on yfinance, like news articles on specific stocks.
